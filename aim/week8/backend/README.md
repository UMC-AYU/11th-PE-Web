# Week 8 backend

Spring Boot movie API with member authentication, favorites, ratings, and transactional movie records.

Copy `src/main/resources/application.example.yaml` to `application.yaml`, then set `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, `JWT_SECRET`, and `JWT_ACCESS_EXPIRATION` in your environment. The local application file is ignored by Git.

Run with `./gradlew bootRun` (or `gradlew.bat bootRun` on Windows).
