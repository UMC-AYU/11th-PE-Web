# 프론트엔드 3주차 미션

- 공개 영화 화면에 라우팅 연결하기
    - 영화 목록, 검색과 상세 화면을 각각 `/`, `/search?query=...`, `/movies/$movieId`에 연결해요.
    - 검색 화면은 `query`와 일치하는 영화를 제공된 로컬 데이터에서 찾아 검색어, 결과 수, 포스터, 제목, 원제, 개봉일과 줄거리를 표시해요. 검색어가 없거나 검색 결과가 없을 때는 각각 알맞은 안내 문구를 표시해요.
    - 상세 화면은 `movieId`와 일치하는 영화 데이터로 Figma 화면을 완성해요. 비교할 때는 배경 이미지가 준비된 `/movies/1`을 사용하고, 존재하지 않는 영화 ID에는 `영화를 찾을 수 없어요.`를 표시해요.
    - 검색 결과와 영화 카드에서 해당 상세 화면으로 이동하고, 각 URL을 직접 입력하거나 새로고침해도 같은 정보가 보이는지 확인해요.
- 기존 CSS를 Tailwind CSS로 옮기기
    - 공개 영화 화면의 기존 CSS를 Tailwind CSS로 옮겨요.
    - 상태에 따라 달라지는 class는 `cn`으로 조합해요.
    - Figma의 데스크톱 화면과 비교한 뒤 Console 오류가 없는지 확인하고 `pnpm build`를 실행해요.

## 프로젝트 구조

- TanStack Router 코드 기반 라우팅에서 파일 기반 라우팅으로 변경
- `App.tsx`의 라우트 정의 및 라우터 생성 코드 삭제
- `/`, `/search`, `/movies/$movieId`에 대응하는 `routes` 파일 분리
- 공통 Header, Footer, Provider를 `__root.tsx` 기반 루트 레이아웃으로 연결
- 영화 화면을 `pages/movies` 폴더로 이동
- 공통 레이아웃 컴포넌트를 `components/layout` 폴더로 분리
- 영화 카드, 그리드, 페이지네이션을 `components/movies` 폴더로 분리
- `lib/cn.ts`를 `utils/cn.ts`로 이동
- TanStack Router Vite 플러그인 추가
- 라우트 정보를 포함하는 `routeTree.gen.ts` 자동 생성
- 라우트별 JavaScript 자동 코드 분할 적용
- 기존 `App.css` 삭제
- 공개 영화 화면의 스타일을 Tailwind CSS 유틸리티로 교체
- 북마크, 활성 메뉴, 별점 등 상태별 클래스를 `cn`으로 조합
- 영화 데이터와 북마크 상태를 공유하는 `MovieContext` 유지

## 검색 화면

### 구현

- 검색 화면을 `/search?query=...` URL에 연결
- URL의 `query` 값을 문자열 검색 파라미터로 검증
- 검색어가 없을 때 Figma 기준 중앙형 검색 화면 표시
- 검색어 입력 후 URL의 `query` 파라미터를 갱신하는 검색 폼 연결
- 영화 제목, 원제, 줄거리에서 검색어를 찾는 로컬 데이터 검색 적용
- 대소문자를 구분하지 않는 검색 처리
- 검색 결과가 있을 때 Figma 기준 2열 결과 목록 표시
- 검색어와 실제 검색 결과 수 표시
- 각 검색 결과에 포스터, 제목, 원제, 개봉일, 줄거리 표시
- 검색 결과별 `상세 보기` 링크 추가
- 검색 결과 선택 시 `/movies/$movieId`로 이동
- 검색어 지우기 및 다시 검색 기능 추가
- 검색 결과가 없을 때 `검색 결과가 없어요.` 안내 표시
- 검색 URL 직접 입력 및 새로고침 후 동일 결과 유지
- 로컬 데이터 기준 `스파이더맨` 검색 결과 2편 표시
